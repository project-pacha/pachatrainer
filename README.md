# പച്ചപയറ്റി
മലയാളം -> പച്ചമലയാളം മൊഴിമാറ്റി
കടമെടുത്ത വാക്കുകൾ കണ്ടുപിടിക്കുകയും അവ പച്ചമലയാളത്തിലേക്ക് മൊഴിമാറ്റുകയും ചെയ്യുന്നത് പയറ്റിപ്പിക്കുന്ന പണിക്കോപ്പ്

## എങ്ങനെയാണ് വാക്കുകളെ കണ്ടെത്തി മൊഴിമാറ്റുന്നത്

മലയാളം വാക്കുകളെ ഒന്നിനുപിറകെ ഒന്നായി ഒട്ടിപ്പിടിപ്പിക്കുന്നതുകൊണ്ട് ഇംഗ്ലീഷിലോ ഹിന്ദിയിലോ ചെയുന്നപോലെ വാക്കുകളെ അടർത്തിയെടുക്കുക എളുപ്പമല്ല. ഇതിനായി ചുവടെപ്പറയുന്ന അടവുകളാണ് എടുത്തിരിക്കുന്നത്.

1. മലയാളം എഴുത്ത് ISO 15919 ലത്തീൻ എഴുത്തുരീതിയിലേക്ക് എഴുത്തുതിരിക്കുന്നു.
2. കടമെടുത്ത വാക്കുകളിൽ പൊതുവെ കണ്ടുവരുന്ന എഴുത്തുകളും, എഴുത്തു മാതിരികളും അതുപോലെ ഏപ്പുകളും (സന്ധി), വേറുകളും (തൽപുരുഷൻ) എങ്ങനെ ഏതൊക്കെ മട്ടിൽ വരുമെന്ന ചട്ടങ്ങൾ നേരത്തെ കൊടുക്കുന്നു
3. പുറമെ മേല്പറഞ്ഞ ചട്ടങ്ങൾക്ക് കീഴിൽ വരാത്ത കടമെടുത്ത വാക്കുകളുടെ ഒരു പട്ടികയും അതുപോലെ മലയാളവാക്കുകളുടെ ഒരു പട്ടികയും കൊടുത്തിരിക്കുന്നു
4. ഇത് തട്ടിച്ചുനോക്കി ഏതാണ്ട് ശരിയായി തന്നെ കമ്പ്യൂട്ടർ കടമെടുത്ത വാക്കുകളെ കണ്ടെത്തുന്നു
